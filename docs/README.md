# 开发文档索引

当前项目为 **OnyxOS**，基于 xv6-riscv 内核骨架演进的 RISC-V 64 位操作系统。文档中的“批次”记录提交历史，“阶段”定义能力与验收范围，两套编号不能直接对应；批次编号的空缺不意味着漏合并。

> 命名说明：项目早期名为 HachileiOS，内部曾以 miniOS 指代本项目。仅存在于历史记录与代码标识中的旧名（如 `kernel/minios.h`、本目录的 `minios-roadmap.md`）保留原文，当前文档统一使用 OnyxOS。

使用顺序：当前行为查仓库 [README](../README.md) 和对应阶段记录；了解设计取舍再读历史计划。历史计划保留原文，不作为要求恢复旧行为的依据。

PR [#4](https://github.com/Miusdy/OnyxOS/pull/4) 的 portable-agent-os 是基于 Linux 的独立实验，原文明确建议与 xv6 两条线并行、不合并。它不在本仓库的默认构建、文件系统镜像或验收链路中；需要推进时应单独确定交付范围。
